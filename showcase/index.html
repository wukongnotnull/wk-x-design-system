Overview

Tokens and components extracted from ccrsxx/twitter-clone. Open this file directly or run python3 -m http.server from this folder.

The clone ships Twitter Chirp (400 / 500 / 700 / 800 and Extended Heavy). This showcase does not redistribute those files and uses system-ui, "Segoe UI", sans-serif instead.
